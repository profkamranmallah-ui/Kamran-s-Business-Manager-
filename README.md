# Kamran's Business Manager

**Shop:** Gulbahar And Sons Super Point  
**Theme:** Blue and gold  
**Currency:** Pakistani Rupees (PKR)

## Included
- Sales and purchase records
- Product and stock tracking with low-stock alerts
- Customer and supplier lists
- Expense tracking
- Estimated profit and loss summary
- JSON backup and restore
- Installable offline-capable Progressive Web App (PWA)

## Install on Android
1. Upload all files in this folder to the root of your GitHub repository.
2. Enable GitHub Pages: repository **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
3. Open the published HTTPS website in Chrome on Android.
4. Use Chrome menu **⋮ → Add to Home screen** or **Install app**.

## Important data note
This first version stores records locally in the browser on the phone. Export backups regularly. It does not yet sync between devices or create an APK file.
